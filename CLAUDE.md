# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Built from the [python-base-flake](https://github.com/schlarpc/python-base-flake) template (see `.cruft.json`), with a Vite + TypeScript web viewer added alongside.

## Environment

- `direnv allow` (or `nix develop`) loads Python with every dependency, Node, and the git hooks. `node_modules` is linked from the Nix store; don't `npm install`.
- `uv add <pkg>` / `uv add --dev <pkg>` change Python dependencies; `npm install --save-dev <pkg>` only updates `package-lock.json` (`.npmrc` is lockfile-only), then re-enter the shell.

## Checks

- `prek run --all-files`: ruff, ruff-format, mypy, pytest, dprint (markdown/json/yaml), shellcheck, nixfmt, sphinx. They also run as a pre-commit hook.
- `npm run check` (tsc, strict) and `npm test` (filtering, Pareto, and the DSP compared against Python via `tests/fixture/`).
- `nix flake check` runs all of the above, including the `web` build.

## Layout

- `src/tbacss/`: the parser, SQLite builder, analysis (a port of TBAC's Octave), and `webexport.py`, which writes the static bundle.
- `web/src/`: the explorer. `tbacss.ts` is the dependency-free bundle reader and DSP; `app.ts` is the UI.
- `scripts/`: source fetching, manifest/provenance generation, `serve.py` (a Range-capable static server), `ui_smoke.mjs` (CDP-driven UI test), and `release_data.sh`.
- `MANIFEST.md`, `PROVENANCE.md` and `tests/fixture/` are generated by scripts; regenerate them rather than editing by hand.

## Data

The release archives (~27 GB), `tbacss.db` (~5 GB) and `web/data/` (~640 MB) are gitignored and are not reproducible in CI. The deployed site is `nix build .#site`: `.#web` plus the bundle fetched from the GitHub release pinned in `web/data-release.json`. See README.md "Deploying to GitHub Pages" and ATTRIBUTION.md for the data's terms.
